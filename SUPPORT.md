# Support

Thanks for using `reqsmith`! Here's where to go depending on what you need.

## Ask a question / discuss an idea

For usage questions, "how do I...", or general discussion (including
questions or proposals about the `.req.yml` request file format), please
use [GitHub Discussions](https://github.com/nabobery/reqsmith/discussions) if
enabled, or open a
[Question / Request Format issue](https://github.com/nabobery/reqsmith/issues/new/choose)
using the appropriate template.

## Report a bug

Open a [bug report](https://github.com/nabobery/reqsmith/issues/new/choose)
using the bug issue template. Please include your `reqsmith` version, OS, and
steps to reproduce.

## Report a security issue

Do **not** open a public issue for security vulnerabilities. See
[SECURITY.md](SECURITY.md) for how to report privately.

## A note on secrets

When asking for help, please **never share real API tokens, credentials, or
captured request/response bodies** in an issue, discussion, or attached
log — even if the endpoint seems harmless. Redact sensitive values or
reproduce the problem with synthetic/fake data.
